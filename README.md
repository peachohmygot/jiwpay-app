# JiwPay · จิ๋วเปย์

React + Vite + Tailwind frontend และ Google Apps Script ธีมน่ารัก ภาษาไทยเป็นหลัก

## ใช้งาน

ติดตั้ง dependencies ด้วย pnpm install แล้ว pnpm dev / pnpm build
ผู้ใช้เข้า / ผู้ดูแลเข้า /#admin
ตั้งค่า GAS URL ผ่าน REACT_APP_GAS_URL หรือใช้ URL ที่กำหนดใน source

## รุ่นล่าสุด

- จำบัญชีและ Admin Key ใน localStorage พร้อม cache และ background refresh
- ป้องกันกดซ้ำ แสดงสถานะส่งรายการ และ optimistic UI พร้อมคืนค่าเมื่อผิดพลาด
- สแกนจ่ายและสแกนรับเงินอยู่เมนูเดียวกัน ร้านค้าสแกนบัตรก่อนใส่ยอด เลือกจ่ายเต็มหรือผ่อน 3/5 งวด ส่วน POS เป็นเครื่องคิดเลขสร้าง QR
- รายการโปรดในการโอนเงิน กล้อง playsInline/autoPlay/muted และ cleanup เมื่อออกจากหน้า
- บัตรแนวนอนสีส้มชมพู บันทึก PNG 1500 × 1000 พิกเซล สำหรับจัดพิมพ์กว้าง 3 × สูง 2 นิ้ว (76.2 × 50.8 มม.)
- ผู้ดูแล → ผู้ใช้ → บัตร Visa / QR → เตรียมรูปบัตรแนวนอน → บันทึกรูปบัตร บน iPhone กดรูปค้างเพื่อบันทึกได้
- QR ไม่ผูกยอดเงินหรือวงเงิน ปรับวงเงินใช้ QR เดิมได้ ออกบัตรใหม่จึงเปลี่ยนรุ่นและยกเลิก QR เก่า
- เวลาเกมเลือก 10/15/20/30/40/60 นาทีจริงต่อวันเกม เปลี่ยนความเร็วไม่รีเซ็ตเวลา มีหยุด/เดินต่อและนับถอยหลังที่หัวทั้งสองแอป
- หน้าแรกผู้ใช้แสดงปุ่มดูบิล / ชำระบัตร และตรวจข้อมูลเมื่อกลับเข้าเว็บ
- บัญชีใหม่สุ่มเฉพาะอีโมจิสัตว์ ไม่เดาเพศ และไม่แก้อีโมจิบัญชีเดิม

## ติดตั้ง

อ่าน DEPLOY-TH.md และ backend/GAME_CLOCK_SETUP_TH.md รุ่นนี้ต้องอัปเดตทั้งเว็บและ backend/Code.gs ใส่ ADMIN_KEY เดิม เรียก installGameClock แล้ว Deploy GAS เวอร์ชันใหม่ก่อนเริ่มเวลาเกม

นาฬิกาเดินแม้ปิดเว็บ จบกิจกรรมต้องกดหยุดเกม Google trigger ตรวจประมาณทุกนาที ไม่รับประกันตรงวินาที ปิดวันย้อนหลังทีละวันเมื่อค้างหลายวัน

## กติกาเดิม

- เงินกู้หักอัตโนมัติเมื่อปิดวัน เงินไม่พอขึ้น missed รอบถัดไปคิดค่างวด + ceil(ค่างวด × rate × จำนวนวันรวมวันเริ่มค้าง) รอบถัดไปจึงนับ 2 วัน
- Visa ผู้ใช้ชำระเอง วันไม่ชำระและงวดยังไม่ครบเพิ่ม ceil(ค่าปรับเดิม + ค่างวด × 5%) ไม่เพิ่มค่าธรรมเนียมออกบัตร
- กระปุกดอกเบี้ย 2% ต่อวันเกม ปัดเป็นบาท ค่าเช่าหักตามสูตรเดิม

## การตรวจสอบ

32 React tests ผ่าน รวม cache, auth, optimistic update, rollback, duplicate submission, scanner lifecycle, เวลาเกม และบิล Visa
backend-card.cjs และ backend-clock.cjs ทดสอบกับชีตจำลอง รวมกู้คืนการปิดวันที่บันทึกธุรกรรมค้างโดยไม่หักเงินซ้ำ
Production build ผ่าน ตรวจมือถือจำลอง 390px ไม่มี runtime error หรือเนื้อหาล้น และถอดรหัส QR จากภาพบัตรที่สร้างได้
previews/ เป็นข้อมูลจำลอง ไม่ใช่ยอดหรือการออกบัตรจริง ยังไม่ได้ทดสอบกล้องบน iPhone/LINE จริง

## ข้อจำกัดของระบบเดิม

localStorage เป็นการจำบัญชีใน UI ไม่ใช่ server session: GAS เดิมยังต้องเพิ่ม token และตรวจสิทธิ์เจ้าของธุรกรรมก่อนใช้เงินจริง
การอนุมัติมี lock และตรวจ pending แล้ว แต่การเขียนหลายชีตไม่ใช่ transaction ต้องเพิ่ม recovery/idempotency ให้ธุรกรรมทุกประเภท
POST ที่เครือข่ายขาดอาจบันทึกบน server แล้ว ต้องตรวจประวัติก่อนส่งซ้ำ ไม่ retry อัตโนมัติ
การแก้ยอดแบบ absolute โดย admin อาจทับข้อมูลล่าสุด ต้องปรับเป็น delta ฝั่ง server
ใช้ HTTPS และอนุญาตกล้อง บาง LINE/WebView ไม่รองรับ ให้เปิด Safari/Chrome

การเปลี่ยนแปลงชุดนี้อยู่ในไฟล์เท่านั้น ยังไม่ได้ push GitHub หรือ deploy ระบบจริง

## ปรับความเร็วรอบล่าสุด

การอ่านเวลาไม่เขียนชีต ไม่ถือ lock และไม่ปิดรอบการเงิน การปิดวันยังทำโดย trigger และก่อนธุรกรรมทางการเงิน พร้อมตรวจซ้ำภายใต้ lock เมื่อข้ามวัน ภายในวันเดียวกันไม่บันทึก snapshot เวลาใหม่ทุกคำขอ การล็อกอินไม่ต้องรอปิดวัน

หน้าเว็บแสดงยอด เวลา และข้อมูลแต่ละส่วนทันทีที่โหลดสำเร็จ ไม่รอประวัติรายการครบ รีเฟรชซ้ำระหว่างโหลดใช้คำขอเดิม แต่หลังทำรายการจะใช้รอบใหม่เพื่อไม่รับผลเก่าทับยอด ยังแยก 6 คำขอเพื่อรองรับ API เดิม ไม่ได้อ้างว่ารวมเป็นคำขอเดียว

ทดสอบเพิ่มเติม: ประวัติค้างไม่กั้นยอดใหม่, รีเฟรชซ้ำไม่สร้างคำขอเพิ่ม, เวลาอ่านได้ขณะล็อกธุรกรรม และการอ่านข้ามวันไม่หักเงินเอง ต้องติดตั้ง installGameClock ตามคู่มือ ขณะรอปิดวันหน้าเวลาจะแสดงสถานะกำลังซิงค์

ความเร็วบนระบบจริงยังไม่ได้วัด ไม่ได้ deploy หรือส่งธุรกรรมจริงในการทดสอบครั้งนี้
